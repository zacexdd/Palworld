Palworld Mobile for iOS

Everything confirmed so far about the iPhone release: App Store status, device requirements, and how to avoid fake downloads.

Last updated: August 02, 2026

Is Palworld Mobile Coming to iPhone?

Yes. iOS is one of the two confirmed platforms for Palworld Mobile, developed by Krafton's PUBG Studios under license from Pocketpair, alongside Android. What hasn't been confirmed is a release date — the game remains in closed regional alpha testing with no global launch window announced.

App Store Release Status

No App Store listing exists yet for Palworld Mobile, and no TestFlight beta has been made publicly available. Krafton has framed the mobile version as a cross-platform release rather than an Android-exclusive title, so a standard App Store launch is expected once the game exits alpha testing.

One factor worth watching: Apple's review process for games involving loot-based creature capture and online multiplayer features tends to be stricter than Google Play's, particularly around age ratings and monetization disclosures. This could mean iOS availability lags slightly behind Android even if both launch within the same broad window.

iOS Requirements: Known vs. Unknown

  • Minimum iOS version: Not announced.
  • Supported devices: Not announced.
  • Storage size: Not announced.
  • Expected chip requirement: Likely a recent A-series or M-series chip, based on requirements for other high-fidelity mobile survival and open-world games on iOS — not officially confirmed.
  • Controller support: Unconfirmed, though iOS natively supports MFi/Bluetooth controllers, which many Krafton mobile titles use.

Confirmed iOS Features

Krafton has confirmed Palworld Mobile will not use a live-service or battle-pass monetization model, matching the PC version's single-purchase structure — this applies across both iOS and Android, not one platform specifically.

The mobile version introduces a new skill-based strategic battle system built for touchscreen controls, along with social features like Pal breeding in a shared Plaza and cooperative or competitive boss battles, first shown publicly at G-STAR 2025.

iOS Alpha Testing Status

A closed alpha test has run for players in Japan and South Korea. Krafton has not specified whether this alpha included iOS devices, Android devices, or both — device breakdowns for the alpha haven't been published.

Why There Is No iOS Download Yet

Because Palworld Mobile hasn't exited closed alpha testing, Krafton has not issued an App Store listing, TestFlight beta, or IPA file for public distribution. Any site offering a "Palworld Mobile iOS download" or sideloading instructions outside of official channels is not legitimate — iOS doesn't support APK files at all, and sideloaded IPAs from unofficial sources carry the same malware and spyware risks as fake Android APKs.

For the latest official news, refer to Krafton's official website. We update this page the moment a real App Store listing or TestFlight beta goes live.
