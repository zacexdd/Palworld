Palworld Mobile for Android

Everything confirmed so far about the Android release: Google Play status, device requirements, and how to avoid fake APKs.

Last updated: August 02, 2026

Is Palworld Mobile Coming to Android?

Yes. Android is one of the two confirmed platforms for Palworld Mobile, developed by Krafton's PUBG Studios under license from Pocketpair, alongside iOS. What hasn't been confirmed is a release date — the game remains in closed regional alpha testing with no global launch window announced.

Google Play Release Status

No Google Play Store listing exists yet for Palworld Mobile. Based on Krafton's distribution model for PUBG Mobile — which launched via Google Play with regular content parity to console/PC — a standard Play Store release is the expected path once the game exits alpha testing, rather than sideloaded APK distribution.

Pre-registration through Play Store "coming soon" listings is a common step Krafton has used for prior titles, though no such listing is confirmed live for Palworld Mobile at this time.

Android Requirements: Known vs. Unknown

  • Minimum Android OS version: Not announced.
  • RAM requirement: Not announced.
  • Storage size: Not announced.
  • Graphics scaling: Expected — the mobile build is anticipated to use scaled-down graphics and asset streaming, since the original PC version requires moderately high specs that most Android hardware can't match directly.
  • Controller support: Unconfirmed, though many Krafton mobile titles support external controllers.

Confirmed Android Features

Krafton has confirmed Palworld Mobile will not use a live-service or battle-pass monetization model, matching the PC version's single-purchase structure — this applies across both Android and iOS, not one platform specifically.

The mobile version introduces a new skill-based strategic battle system built for touchscreen controls, along with social features like Pal breeding in a shared Plaza and cooperative or competitive boss battles, first shown publicly at G-STAR 2025.

Android Alpha Testing Status

A closed alpha test has run for players in Japan and South Korea. Krafton has not specified whether this alpha included Android devices, iOS devices, or both — device breakdowns for the alpha haven't been published.

Why There Is No APK Yet

Because Palworld Mobile hasn't exited closed alpha testing, Krafton has not issued any APK — official or otherwise — for public distribution. Any file labeled "Palworld Mobile APK" found on third-party sites is not the real game. These are typically repackaged unrelated apps, adware bundles, or in worse cases spyware using Palworld branding and screenshots to appear legitimate.

For the latest official news, refer to Krafton's official website. We update this page the moment a real Play Store listing or APK goes live.
